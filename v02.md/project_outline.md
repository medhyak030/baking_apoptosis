# Version 2 — Computational Pipeline

### Motto
Version 2 transitions the project from conceptual biology to computational biology.

The primary objective is to construct a reproducible computational workflow capable of retrieving biological sequence data, analysing receptor architecture, comparing evolutionary conservation, and generating interpretable biological observations that support the project's hypotheses.

Rather than performing manual analyses, each computational step will gradually be automated using Linux, Bash and Python.

### Long Term Goal
Develop a reproducible computational framework capable of analysing TRAIL receptor architecture, sequence conservation and functional variation while directly supporting the biological hypotheses developed throughout this project.

Future versions may extend the framework to include structural modelling, mutation prediction, evolutionary analysis and other computational approaches as the project evolves.
