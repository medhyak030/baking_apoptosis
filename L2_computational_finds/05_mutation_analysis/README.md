# Layer 2.5 --- Mutation Analysis

## Purpose

This stage will examine sequence differences in the context of the
receptor architecture established by the earlier stages.

The aim is to distinguish sequence variation from variation that occurs
within or near structurally/functionally important regions.

## Inputs

The planned analysis will use aligned receptor sequences, domain/region
coordinates, conservation information, and sequence differences between
species.

## Planned workflow

1.  Identify substitutions or other differences in the alignment.
2.  Locate the corresponding positions within the receptor architecture.
3.  Determine whether changes occur inside or outside annotated regions.
4.  Compare variation with conservation.
5.  Flag differences that warrant biological interpretation.

## Interpretation

A sequence difference is not automatically a damaging mutation. The
computational analysis can identify where variation occurs and whether
it lies in a constrained region. Functional consequences require
biological evidence and should not be inferred from sequence difference
alone.

## Connection to the project

This stage addresses the Layer 2 questions: which regions are
evolutionarily constrained, where sequence variation can occur without
disrupting receptor architecture, and how sequence variation may relate
to regulation of receptor-mediated apoptosis.
